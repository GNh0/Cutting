# Cutting

개인용 **판재 절단 최적화 웹사이트**입니다. 설치·로그인·계산 서버 없이 브라우저에서 실행합니다.

**웹사이트: [gnh0.github.io/Cutting](https://gnh0.github.io/Cutting/)**

## 사용법

1. 절단 부재에 가로·세로·수량을 입력합니다.
2. 보유 원판에 치수·재고 수량을 입력합니다. 각 행의 `···`에서 재질·결 방향을 지정합니다.
3. 톱날 두께와 원판 가장자리 여유를 설정하고 **최적 배치 계산**을 누릅니다.
4. 배치도·절단 순서·미배치 부재·상세 통계를 확인합니다.
5. 현재 원판은 SVG/PNG, 전체 원판과 절단표는 인쇄/PDF로 저장합니다.

원판 한 장만 사용, 회전 허용, 재질별 배치, 결 방향 유지, 부재별 밴딩 표시, 30/120/240개 후보 탐색을 지원합니다. CSV·엑셀 셀 붙여넣기, 결과 CSV, JSON 프로젝트 백업, 브라우저 보관함도 제공합니다.

단위는 mm/cm/m/inch입니다. 단위를 바꿔도 실제 크기는 유지됩니다. CSV는 현재 표시 단위로 읽습니다. 재질명은 앞뒤 공백을 제거한 뒤 정확히 비교하며, 재질 구분이 켜져 있으면 이름이 같아야 배치됩니다. 결 미지정은 자유 방향입니다. 엣지밴딩은 위치 표시와 필요 길이 계산용이며 치수를 차감하지 않습니다.

## 개발 실행

Node.js 22 이상 권장. 사이트 자체는 외부 패키지·CDN 의존성이 없습니다.

```sh
npm start
# http://127.0.0.1:4173
npm test
npm run check
```

ES Modules와 Web Worker를 사용하므로 `index.html`을 파일로 직접 여는 대신 HTTP(S) 주소로 실행합니다. GitHub Pages는 `main` 브랜치 루트에서 제공합니다. `.nojekyll`이 포함되어 별도 빌드가 필요 없습니다.

## 계산 방식

독립 구현한 길로틴 휴리스틱입니다. 한 번의 절단은 현재 조각을 끝까지 가로지릅니다. 네 탐색 계열을 함께 실행하는 하이브리드입니다. 여러 부재 정렬, 공통 치수별 띠 배치, 큰/작은 원판 우선, 잔여 영역 점수, 가로/세로 분할을 비교합니다. 기본 순서는 미배치 수량, 미배치 면적, 사용 원판 면적, 재사용 잔재 점수, 절단 횟수, 총 절단 길이입니다. 잔재 점수는 재사용 가능 총면적 + 최대 재사용 잔재 면적의 10%이며, 두 변이 최소 폭 설정 이상인 잔재만 집계합니다. `큰 잔재 우선`은 총면적 점수 대신 최대 잔재부터 비교합니다. `절단 횟수 최소` 설정은 원판 면적보다 절단 횟수를 먼저 비교합니다.

절단선의 오른쪽/아래쪽에 톱날 폭을 확보합니다. 원판과 정확히 일치하는 경계에는 불필요한 톱날 여유나 절단을 추가하지 않습니다. 가장자리 여유는 네 면의 사용 불가 영역으로, 정재단 절단은 표의 횟수·길이에서 제외됩니다. 이용률은 부재 면적 / 사용 원판 전체 면적입니다. 남는 면적에는 톱날과 가장자리 여유가 포함됩니다.

휴리스틱이므로 수학적 최적해를 보장하지 않습니다. 부재 수량 합계와 각 입력 행은 최대 1,000입니다. 이 제한은 작업 크기 제한이며, 계산 실행 횟수 제한은 없습니다.

## 데이터 보관

입력값은 계산 서버에 전송하지 않고 브라우저의 `localStorage`에 저장합니다. 기기/브라우저별로 별도 보관하며 자동 동기화하지 않습니다. 브라우저 데이터를 지우면 보관함도 삭제되므로 JSON 파일 백업을 권장합니다. 사이트 접속 자체는 GitHub Pages를 이용합니다.
