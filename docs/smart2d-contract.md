# Smart2DCutting 3.5 공개 동작 계약 조사

조사일: 2026-10-23. 설치본의 읽기 전용 문서와 Rasterweq 공식 도움말을 대조했다. 이 문서는 관찰된 입력·설정 계약과 독립 구현 제안을 구분한다. 원본 내부 계산식의 복구나 결과 일치를 증명하지 않는다.

## 확인한 근거

- 설치 문서: `C:\Program Files (x86)\Smart2DCutting\readme.txt` 12행은 3.5, 20~21행은 사전 절단 치수와 부재 치수에서 밴드 두께 차감, 42행은 여러 원판 크기 처리 개선을 명시한다.
- 같은 문서 104행은 전체/재질별 톱날 폭, 116~118행은 큰 부재용 최적화 수준과 원판별 트림·부재별 여유를 명시한다. 228~233행의 Quick/Full은 과거 버전 변경 이력이므로 현재 3개 수준을 2개로 해석하면 안 된다.
- [공식 최적화 도움말](https://rasterweq.com/help/06_0optimization.htm): 방향은 가로·세로·자동이며 수준은 1·2·3이다. 방향만 전체 선택하면 3회, 수준만 전체 선택하면 3회, 양쪽 전체 선택하면 9회 실행한다. 후보 결과표에서 최선 결과가 강조된다. 도움말은 작업마다 가장 좋은 수준이 달라질 수 있다고 설명한다. 사전 절단은 지정 길이에서 원판을 나눈다. 중단 시 결과는 미완성일 수 있다.
- [공식 최적화 설정](https://rasterweq.com/help/04_1optimization.htm): 사용률 임계값과 남은 부재·원판 수량이 반복 배치 조건이다. 잔재 우선 임계값을 만족하면 사용률이 더 높은 새 원판보다 잔재를 선택할 수 있다. 재고 한정은 원판 수량을 실제 재고로 제한한다. 동일 치수의 다른 부재 번호를 묶는 표시 옵션은 설명·코드 구분 손실에 주의해야 한다. Smart-Trim은 원판 끝에 정확히 맞는 배치를 허용하면서 가장자리 트림 거리 안쪽 절단을 배제한다. 여러 원판 크기 최적화와 전체/재질별 톱날 폭을 지원한다.
- [공식 제품 사양](https://rasterweq.com/specifications.htm)은 3.5, 부재별 결 방향, 원판·부재 여유, 여러 재질과 원판 크기를 명시한다. 사이트의 평균 수율·실행시간은 제작사 예시이며 Cutting의 성능 근거로 사용할 수 없다.

## 확인되지 않은 항목

공식 문서에는 guillotine 재귀 분할, strip 채우기, 분할 순서, 정렬 기준, 탐색 폭, 목적함수 가중치, 최선 후보의 정확한 동률 해소 규칙이 공개되어 있지 않다. 세 방향과 세 수준을 제공한다는 사실만으로 아홉 개의 내부 알고리즘이나 2단 절단 제약을 특정할 수 없다. Ghidra/REA의 별도 근거 없이 특정 함수가 실제 최적화 코어라고 단정해서는 안 된다.

설치 CHM의 사본 추출을 `hh.exe -decompile`로 64비트/32비트 각각 시도했으나 두 프로세스 모두 즉시 종료했고 파일을 생성하지 않았다. 설치본 변경이나 앱 실행은 없었다. 대신 위 공식 웹 도움말을 사용했다. 빈 `research/smart2d-help` 디렉터리에는 계산 근거가 없다.

## 독립 계산 버전 설계 제안

다음 수식은 Cutting에서 설계하는 새 휴리스틱이며 Smart2DCutting 내부 수식으로 주장하지 않는다.

1. 원판 유효 크기는 `W = 원판가로 - 좌트림 - 우트림`, `H = 원판세로 - 상트림 - 하트림`으로 계산한다. 부재 여유·밴드 차감은 별도 입력 계약이 있을 때만 적용한다.
2. 회전 허용과 재질·두께·결 방향을 먼저 검사한다. `dw = 빈공간가로 - 부재가로`, `dh = 빈공간세로 - 부재세로`이다. 각 차이는 0이거나 톱날 폭 이상이어야 한다. 0이면 해당 방향 절단이 필요 없다.
3. 수직 우선 분할은 오른쪽 `(dw - kerf) × 빈공간세로`와 아래쪽 `부재가로 × (dh - kerf)`를 생성한다. 수평 우선은 아래쪽 `빈공간가로 × (dh - kerf)`와 오른쪽 `(dw - kerf) × 부재세로`를 생성한다. 음수·0 잔여 공간은 생성하지 않는다.
4. 방향별 후보와 부재 정렬·빈공간 점수 조합을 독립적으로 실행한다. 예: 빈 면적 최소화, 짧은 잔여 변 최소화, 절단 길이 최소화. 각 수준의 탐색 예산을 명시하고 높은 수준이 낮은 수준의 후보도 포함하게 하면 계산 예산 증가 시 최선 결과가 악화되지 않는다.
5. 완성도, 사용 원판 면적/수량, 실제 절단 길이, 재사용 잔재를 현재 Cutting 우선순위대로 비교한다. 원본의 미공개 가중치를 추정한 상수를 사실처럼 넣지 않는다.
6. 저장·내보내기에는 안정적인 계산 버전 ID를 포함하고 예전 문서는 기존 버전으로 읽는다. 새 버전은 실험 표시와 근거 문서를 제공한다. 최적화 후 버전 선택이 바뀌면 기존 결과의 출처 표시를 유지하고 재계산 전까지 결과가 새 버전인 것처럼 보이지 않게 한다.

현재 입력 모델이 지원하지 않는 Smart-Trim, 밴드 차감, 사전 절단, 재질별 kerf를 자동으로 지원한다고 표시하지 않는다. 등록되는 버전은 실제 구현한 설정만 설명해야 한다.
