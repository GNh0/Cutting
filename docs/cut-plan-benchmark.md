# 그룹 배치와 절단 계획 검증

배치 후보를 비교해 부재 위치와 원판을 선택한 다음, 위치를 고정한 채 공통 절단 트리를 탐색하고 실행 순서를 정리합니다. 공통 절단은 현재 한 조각을 끝까지 가로지르는 경우에만 허용합니다. 먼저 조각을 분리하는 부모 절단이 완료된 뒤에 자식 절단을 실행합니다. 실행 가능한 절단 중 같은 방향과 같은 작업 띠를 우선하고 좌표 순서로 진행합니다. 이미 분리한 원판 조각을 다시 붙이거나 여러 조각을 포개 자르는 작업은 가정하지 않습니다.

공통선 탐색은 원판당 부재 2~48개, 최대 512개 상태로 제한합니다. 대안을 찾지 못하거나 부재가 더 많으면 기존 절단을 보존하고 실행 순서를 정리합니다. 최적해의 증명이나 전수 탐색 결과가 아닙니다.

## 배포 코드의 확인 결과

- 자동 테스트 48개 통과. 화면에서 제시된 19개 부재, 5개 부재의 같은 길이 공통선, 선후관계, 두께·재질·제조사·LOT별 배치 및 잔재를 포함합니다.
- [생산 코드 회귀 검증](production-verification.json): 1,000개 혼합 조건, 1,590장에 대해 실제 절단 조각 재생·부재 수량·재고·그룹 일치 검사 통과. 기존 검증 조건을 다시 사용한 회귀 검사입니다.
- [복합 조건 검증](complex-backtest-100-48.json): 별도 100개 조건, 24~47종 부재, 57~1,000개 수량, 3~4개 그룹과 9~12종 원판, 결 방향·회전 제한·재고 부족·소수 치수·여유 조건. 30개 대량 조건 중 10개는 부재 1,000개입니다. 이전 조건과 물리 조건 지문 중복이 없습니다.
- 각 복합 조건에서 그룹당 배치 후보 240개와 기준 계열 48개를 비교했습니다. 총 100,800개 배치 후보와 300회 물리 검사를 실행했습니다. **기준은 단일 계열 48개이며, 직전 배포의 하이브리드 240개와 비교한 개선율이 아닙니다.**
- 선택한 복합 배치의 절단 횟수 33,266 → 30,230회. 이는 100개 조건 합계이며 모든 조건에서 같은 감소율을 보장하지 않습니다.

## 직전 배포와 동일 입력 비교

[19개 부재 비교 기록](release-comparison.json)은 직전 배포 `6af9b30`을 직접 실행한 결과입니다. 측판 800×300 2개, 선반 564×300 4개, 상·하판 600×320 10개, 뒷판 764×564 1개, 보강대 564×80 2개, 원판 2440×1220 3장, 톱날 3mm, 가장자리 0mm, 재사용 최소 폭 100mm입니다.

부재 위치는 같습니다. 이 입력의 배치 이용률 개선은 0%p이며 절단 횟수는 약 3.8% 감소했습니다. 이번 변경의 주된 성과는 그룹 일치 조건, 공통 절단 계획과 순서, 결과 화면 개선입니다.

## 앞선 시험과 미완료 범위

`cut-plan-benchmark.json`의 100,000개 조건 및 `cut-plan-complex-1000.json`의 복합 1,000개 조건은 앞선 절단 탐색 코드의 측정입니다. 생성기가 같거나 파일 이름이 비슷해도 최종 배포 코드의 결과로 바꾸어 설명하지 않습니다. 각 파일의 소스 해시로 구별합니다. 파일럿 조건은 서로 겹칠 수 있어 독립 시나리오 합계로 더하지 않습니다.

복잡한 조건 100만 건의 최종 검증은 완료되지 않았습니다. 추가 대량 실행을 늘리지 않고 이번 배포를 진행합니다. 새로운 탐색 전략을 도입하면 별도 비교 입력과 같은 계산 예산으로 다시 검증해야 합니다.
