# 독립 입력 1,000개 계산 버전 백테스트

2026-10-23. 서로 다른 무작위 복합 입력 **1,000개**를 만들고, 각 입력을 두 계산 버전에 그대로 넣었다. **정밀(thorough)·자재 우선(area)** 설정을 고정했다. 입력당 1회씩 비교하여 총 1,000쌍, 엔진 실행 2,000회이다. 탐색 수준을 바꿔 같은 입력을 독립 횟수로 더하지 않았으며, 실행 시간은 측정하거나 승패에 사용하지 않았다.

## 같은 생산 결과의 이용률·로스율 우세 횟수

두 엔진의 **부재 종류별 배치 수량까지 같은 721개**에서 이용률과 로스율을 각각 센다. 나머지 279개는 생산한 부재 구성이 달라 자재 지표 승패에서 분리했다. 같은 수량·면적만으로 동일 생산이라고 간주하지 않는다.

이용률·로스율에서 상대보다 나쁘지 않고 하나 이상 우세한 경우: 기존 299개, 분석 버전 152개. 두 지표 모두 동률 23개, 두 지표의 우세 엔진이 서로 엇갈린 경우 247개이다. 엇갈린 작업에 임의의 종합 승자를 붙이지 않았다.

양쪽 모두 주문 부재를 전량 배치한 작업은 153개, 기존만 전량 배치 0개, 분석 버전만 전량 배치 0개, 양쪽 모두 일부 미배치 847개이다. 전체 1,000개 중 배치 수량이 더 많은 쪽은 기존 177개·분석 버전 43개·수량 동률 780개였다. 수량만 같아도 부재 종류가 다르면 자재 효율의 동일 생산 비교에 넣지 않았다.

## 매번 새로 생성한 입력

작업별 부재 12~47종·수량 37~432개, 원판 4~20종이다. 부재 치수 85~2,239.2 × 60.1~1,469.7 mm, 원판 치수 850~3,199.6 × 600.4~2,099.6 mm, 두께 6~30 mm를 생성했다. 재질·제조사·LOT과 지정/미지정 요청, 결·회전 제한, 수량과 재고 구성을 매번 생성했다. 톱날 0.5~6 mm, 트림 0.1~15 mm, 최소 잔재 폭 40~219.8 mm이다. 대량 수량 조건 120개, 재고 부족 유도 조건 223개를 포함하며 원판 한 장 제한·결 적용·전체 회전 설정도 섞었다. 이 범위와 비율은 공개한 1,000개 seed 집합의 실제 값이다.

## 판정 수식과 검증

- 자재 이용률 = 배치 부재 면적 ÷ 실제 사용 원판 면적 × 100. 높을수록 좋다.
- 재사용 잔재 = 가로·세로가 모두 해당 작업의 최소 잔재 폭 이상인 조각.
- 폐기 로스 = 사용 원판 면적 − 배치 부재 면적 − 재사용 잔재 면적. 재사용 잔재를 폐기 로스로 세지 않는다.
- 폐기 로스율 = 폐기 로스 ÷ 실제 사용 원판 면적 × 100. 낮을수록 좋다.
- 폐기 로스 = 트림 소모 + 톱날 소모 + 재사용 불가 작은 잔재. 모든 실행에서 면적 보존과 이 합계를 검사했다.
- 비율 차이가 0.0000001%p 이하이면 동률로 처리한다.

2,000회 모두 물리 절단 재생, 부재 중복·누락, 재고·재질·결·회전 제한 및 로스 합계 검사를 통과했다. 입력 변경 여부와 부재 종류별 생산량도 확인했다. 실패 작업을 제외해 승률을 높이지 않았다.

비교 대상은 Cutting의 기존 cutting-v1과 독립 실험 엔진 smart2d-v1이다. 원본 Smart2DCutting EXE와 직접 비교한 결과가 아니다. 이 합성 입력 분포에서의 결과이며 모든 실제 작업의 우열이나 수학적 최적해를 증명하지 않는다. 기본 계산식은 기존 v1로 유지한다.
