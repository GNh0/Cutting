# 자재 이용률·재사용 잔재·로스 기준 계산식 비교

2026-10-23. 같은 복합 입력을 두 엔진에 넣고 **부재 배치 완성도, 자재 이용률, 재사용 잔재, 버려지는 로스**로 비교했다. 실행 시간·처리 속도·절단 횟수는 승패 기준과 결과 표에 포함하지 않는다.

비교 대상은 Cutting의 `cutting-v1`과 독립 실험 엔진 `smart2d-v1`이다. 원본 Smart2DCutting 프로그램과 직접 대결한 결과가 아니다. [Smart2D 분석 근거와 한계](smart2d-analysis.md).

## 입력과 판정 기준

서로 다른 복합 입력 36개를 빠르게·균형·정밀 3개 탐색 수준으로 실행했다. 총 108회 비교, 엔진 실행은 216회이다. 부재 24~44종·활성 수량 56~942개, 원판 9~12종이며 재질·두께·제조사·LOT, 제조사/LOT 미지정의 재고 공유, 결 방향, 회전 제한, 소수 치수, 톱날 0.8~5 mm, 트림 0~10 mm, 재사용 잔재 최소 폭 60~150 mm와 재고 부족 조건을 섞었다. **두 엔진 모두 원판 최소·자재 우선 설정**으로 실행했다.

판정 순서는 다음과 같다.

1. 미배치 수량을 최소화하고, 같으면 미배치 면적을 최소화한다. 부재를 덜 만들어서 이용률이나 사용 원판이 좋아 보이는 결과를 방지한다.
2. 같은 부재 수량·면적을 배치했다면 사용 원판 면적이 작은 쪽, 즉 자재 이용률이 높은 쪽을 우선한다. 원판 크기가 다르므로 장수만 비교하지 않는다.
3. 같은 원판 면적에서는 버려지는 로스가 적은 쪽을 우선한다.
4. 이 조건들도 같으면 가장 큰 재사용 잔재를 남긴 쪽을 우선한다. 모든 자재 지표가 같으면 동률이다.

수식은 다음과 같다.

- 자재 이용률 = 배치한 부재 면적 ÷ 사용한 원판 면적 × 100.
- 재사용 잔재 = 가로·세로가 모두 같은 작업의 최소 폭 설정 이상인 잔재.
- 버리는 로스 = 사용 원판 면적 − 부재 면적 − 재사용 잔재 면적.
- 버리는 로스는 톱날 소모 + 가장자리 트림 + 재사용할 수 없는 작은 잔재로 구분한다.
- 유효 자재 회수율 = (부재 면적 + 재사용 잔재 면적) ÷ 사용 원판 면적 × 100.

전체 실행에서 절단선을 물리 조각에 재생해 배치·절단·재질·결·재고·면적 보존을 검사했다. 추가로 로스가 위 세 종류의 합과 일치하는지도 216회 모두 확인했다.

## 같은 부재 수량·면적을 배치한 결과만 비교

108회 중 **63회는 양쪽의 배치 수량과 배치 면적이 같았다**. 이 63회는 생산량 차이 없이 자재 이용률과 로스를 비교할 수 있다.

| 자재 지표 | 기존 Cutting v1 | 새 Smart2D 분석 v1 |
|---|---:|---:|
| 배치한 부재 수량 합계 | 7,205개 | 7,205개 |
| 배치한 부재 면적 합계 | 1,630.304㎡ | 1,630.304㎡ |
| 사용 원판 면적 합계 | **2,222.410㎡** | 2,257.649㎡ |
| 자재 이용률 | **73.36%** | 72.21% |
| 재사용 잔재 면적 합계 | 502.065㎡ | 534.791㎡ |
| 버리는 로스 합계 | **90.041㎡** | 92.555㎡ |
| 로스율 | **4.052%** | 4.100% |
| 유효 자재 회수율 | **95.948%** | 95.900% |
| 자재 기준 우세 횟수 | **43회** | 20회 |

이 표의 면적·수량은 63회 실행의 합계이며 한 작업의 수치가 아니다. 이용률과 로스율은 면적을 합산해 계산한 가중 비율이다. 같은 물리 입력의 여러 탐색 수준이 포함되므로 63개의 독립 작업이라고 해석하지 않는다.

새 버전이 재사용 잔재를 약 32.726㎡ 더 남겼지만, 원판도 약 35.239㎡ 더 사용했다. **남긴 잔재 양만 크다고 효율이 더 좋은 것은 아니다.** 동일 생산량에서 기존 버전이 원판을 덜 쓰고 폐기 로스도 약 2.513㎡ 줄였다.

## 전체 108회 결과와 탐색 수준별 차이

| 탐색 수준 | 기존 v1 우세 | 새 버전 우세 | 동률 |
|---|---:|---:|---:|
| 빠르게 | 28 | 8 | 0 |
| 균형 | 28 | 8 | 0 |
| 정밀 | 21 | 15 | 0 |
| 전체 | **77** | **31** | 0 |

전체 비교는 미배치 수량·면적을 먼저 포함한 결과다. 기존은 총 12,639개, 새 버전은 12,514개를 배치했다. 양쪽의 생산량이 다른 이 전체 합계에서 잔재나 로스만 떼어 우열을 판단하지 않는다.

정밀 수준에서 동일 배치 수량·면적인 23회만 보면 기존 11회, 새 버전 12회 우세였다. 이 23회의 가중 자재 이용률은 기존 73.312%, 새 버전 73.379%로 새 버전이 조금 높고, 폐기 로스는 기존 29.981㎡, 새 버전 30.099㎡로 기존이 조금 작았다. 이용률과 재사용 잔재·로스의 교환 관계가 있어 모든 작업에 한 엔진이 우월하다고 단정할 수 없다.

이번 복합 조건 전체에서는 **기존 v1을 기본으로 유지할 근거가 있다**. 새 버전은 일부 배치의 자재 이용률을 높이는 대안으로 남긴다. 이 결론은 처리 속도가 아닌 실제 자재 배치·잔재·로스에 근거하며, 수학적 최적해나 원본 Smart2DCutting 대비 우열을 증명하지 않는다.

```powershell
npm run benchmark:versions
```
